# Which document should I read first?

If you are completely new to Android Studio, use this order:

1. `README_FIRST.md` in the project root: a one-page orientation and run checklist.
2. `docs/BEGINNER_SETUP_GUIDE.md`: detailed Android Studio setup and optional Firebase setup.
3. `docs/USER_GUIDE.md`: how the employee and manager screens work.
4. `docs/PROJECT_PROPOSAL_AND_REQUIREMENTS.md`: the project purpose, scope, and requirements.
5. `docs/SYSTEM_DESIGN_AND_DATABASE.md`: source code layers, database documents, and security rules.
6. `docs/TEST_PLAN.md`: use this list to test the demo and later the Firebase version.

Each of the five full documents is also supplied as `.docx` in `docs/Word/` and `.pdf` in `docs/PDF/`.
